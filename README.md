# Naz-Store
website jual beli akun game

## Prototype awal: katalog top-up game

Versi pertama Naz-Store berisi demo frontend terinspirasi alur top-up game. Ini belum menjadi marketplace jual-beli akun ataupun layanan transaksi sungguhan.

Fitur demo:
- Beranda dengan katalog 8 game, pencarian dan filter kategori.
- Pilihan nominal, input ID game, serta metode pembayaran simulasi.
- Pembuatan kode pesanan dan pelacakan lokal dengan `localStorage`.
- Desain responsif untuk HP dan laptop.

Buka `dist/index.html` untuk menjalankannya tanpa instalasi. Data produk dan harga contoh ada di `dist/app.js`, sedangkan desain di `dist/styles.css`.

**Penting:** Belum ada pembayaran otomatis, backend, penyedia produk digital, verifikasi akun, atau pengiriman item sungguhan. Jangan memasukkan data akun pribadi saat mencoba.
